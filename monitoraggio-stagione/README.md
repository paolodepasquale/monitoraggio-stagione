# Swimbrain

Allenamenti, presenze (vasca e palestra), carichi di lavoro (sRPE, ACWR, monotonia), zone A1–C2
e di Maglischo, lavori per gruppi, settimana e stagione, gare e tempi della squadra di nuoto.

**Sito:** https://paolodepasquale.github.io/monitoraggio-stagione/monitoraggio-stagione/

## Installarla come app
- **Android (Chrome):** apri il sito → menu ⋮ → *Installa app* (o *Aggiungi a schermata Home*).
- **iPhone / iPad (Safari):** apri il sito → *Condividi* → *Aggiungi alla schermata Home*.
- **PC (Chrome / Edge):** icona *Installa* nella barra dell'indirizzo.

L'app si apre anche senza rete; le modifiche fatte offline partono appena torna la connessione.

## I dati
Il codice non contiene dati della squadra. I dati stanno nel Foglio Google della squadra:
in *Dati → Foglio Google* si inseriscono l'indirizzo dell'app web dello script (…/exec)
e la parola d'ordine. Con il pulsante *Link per lo staff* si manda un link che apre il sito
con l'indirizzo già scritto: la parola d'ordine va data a parte, solo allo staff.

## Aggiornamenti
A ogni pubblicazione i telefoni scaricano da soli la versione nuova alla prima apertura con rete;
si vede dall'apertura successiva.
